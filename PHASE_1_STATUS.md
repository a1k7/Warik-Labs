## Local checkout

Run these commands from your existing Warik-Labs clone:

```bash
git status --short --branch
git fetch origin
git switch --track -c phase-1/scaffold origin/phase-1/scaffold
```

If the branch already exists locally, use `git switch phase-1/scaffold` instead of the last command.

## Configure local environment

```bash
cp .env.example .env.local
cp apps/console/.env.example apps/console/.env.local
```

Edit only the local root `.env.local` for API configuration. Keep the newly generated JWT secret there if you want it ready for the authentication phase. Do not paste it into chat or commit it. The console file contains only the public API base URL.

## Start local services

Terminal 1 — infrastructure:

```bash
docker compose up -d postgres redis
docker compose ps
```

Terminal 2 — API:

```bash
cd apps/api
python3.13 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Terminal 3 — dashboard (from repository root):

```bash
corepack enable
corepack prepare pnpm@12.21.0 --activate
pnpm install
pnpm --filter @warik/console dev
```

Open `http://localhost:3000`. API docs are at `http://localhost:8000/docs`; liveness is `http://localhost:8000/api/v1/health/live`, and readiness is `http://localhost:8000/api/v1/health/ready`.

## Deliberate non-features in this phase

- No WhatsApp number, Meta credentials or inbound webhook is connected.
- No LLM API key is required or called.
- No browser worker or live external action is enabled.
- No flight/grocery/food/cab API is called.
- Payments are excluded; live browser actions are locked off.
- No credential from the old repository, Render environment, archive or chat was copied.
- The Compose Postgres password is a public, local-development-only value. Never use it outside a developer machine.
