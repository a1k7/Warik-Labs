# Warik Labs API

FastAPI service for the Warik execution runtime.

## Local development

From the repository root:

```bash
docker compose up -d postgres redis
cd apps/api
python3.13 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

API docs: http://localhost:8000/docs  
Liveness: http://localhost:8000/api/v1/health/live  
Readiness: http://localhost:8000/api/v1/health/ready

## Configuration

The API reads the root `.env.local` or `.env` when launched from `apps/api`. The root `.env.example` documents the supported variables. The local database and Redis defaults are for developer machines only.

The API does not connect to third-party providers during startup. A successful liveness response means only that the process is serving requests. Readiness additionally checks the configured database and Redis.

## Migrations

```bash
alembic upgrade head
alembic revision --autogenerate -m "describe schema change"
```

Always inspect autogenerated revisions before applying them. Do not use SQLAlchemy `create_all()` as a deployment migration strategy.
